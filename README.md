# English Hub Apps — 英語授業用Webアプリの「設計書」と「見本のコード」

英語の授業や校務で使っている Web アプリを、**AI に作らせて自分の学校で動かす**ための材料です。

- 各アプリの **要件定義（略案）**：`apps/<アプリ名>/README.md`
- **見本のコード**：`apps/<アプリ名>/` の HTML・CSS・JavaScript（架空のサンプルデータで動く画面のデモ。通信はしません）

## なぜ「アプリ」ではなく「設計書」を配るのか

アプリそのものを配ると、使う先生の学校の生徒の情報（氏名・作文・成績など）が、**配った人の管理するサーバーを通る**ことになります。他校の生徒の情報を預かることはできません。

そこで、設計書と見本を公開しています。これを AI に渡せば、**自分（自分の学校）が管理するアプリ**として作れます。生徒の情報は、自分の管理の外に出ません。

## 使い方（AIに再現してもらう）

**いちばん簡単な方法**：デモサイトの各アプリの「要件定義」ページにある「AIに再現して」ボタンを押すと、要件定義の全文入りの依頼文がコピーされます。GitHub を読めない AI（学校アカウントの Gemini など）でも、そのまま貼り付ければ作れます。

GitHub のページを読める AI なら、次のように頼むこともできます。

プログラムを書ける AI（Claude Code など）に、次のように頼みます。`<アプリ名>` は下の表のフォルダ名に置き換えてください。

```
次のGitHubリポジトリにあるアプリを参考に、同じ機能のWebアプリを私の環境で作ってください。

・要件定義（設計書）: https://github.com/Masahieo-A/english-hub-apps/blob/main/apps/<アプリ名>/README.md
・見本のコード（架空データで動く画面のデモ）: https://github.com/Masahieo-A/english-hub-apps/tree/main/apps/<アプリ名>

進め方：
1. まず要件定義と見本のコードを読んでください。作り始める前に、分からない点と、私が決めるべき点を質問してください。
2. 見本のコードは、見た目と操作の流れの参考です。本物の機能（ファイルの読み込み、AIとの連携など）は要件定義に従って作ってください。
3. 生徒の個人情報（氏名など）は、外部のAIやサービスに送らない設計にしてください。
4. APIキーなどの秘密情報はコードに書かず、環境変数に置いてください。
5. 私はプログラミングの専門家ではありません。手順は日本語で、1つずつ説明してください。
```

## 見本を手元で開く

ダウンロード（Code > Download ZIP）して、`index.html` をブラウザで開くだけで動きます。

## 「エラーが起きたら？」「引き継ぎは？」

引き継ぐのはコードではなく **要件定義（日本語の設計書）** です。エラーが出たら、エラーの文面と要件定義を AI に見せて直させます。作った人がいなくなっても、要件定義があれば次の人が AI に作り直させられます。アプリを直したら、要件定義も一緒に直しておくことが大切です。
