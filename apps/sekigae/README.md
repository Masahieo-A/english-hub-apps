# 席替えアプリ 要件定義（略案）

> 名簿の Excel を読み込み、配慮事項を守った座席表を3パターン自動で作る教員用アプリ。名簿はブラウザの中だけで処理する。

## 1. 目的
- 席替えのたびに手作業で座席表を作る手間をなくす。
- 「前の席に座らせたい」「この2人は離したい」「この生徒はこの辺りの席に」といった配慮を、生徒に気づかれずに反映する。
- 毎回違う結果を3パターン出し、教員が選べるようにする。

## 2. 使う人
- 担任・教科担当の教員（操作はすべて教員）。教室のプロジェクターに結果を映して使うことが多い。
- 生徒はアプリに触れない。結果の画面を見るだけ。

## 3. 主な機能
**必須**
- 名簿の読み込み（.xlsx／.xls／.csv。A列＝出席番号、B列＝氏名、C列＝性別「男」「女」。1行目が見出しでも読める）。ドラッグ＆ドロップとファイル選択の両方。
- 読み込み時の点検：生徒0人、座席数（6列×7行＝42席）を超える人数、出席番号の重複、性別が「男」「女」以外、をエラー表示。
- 条件設定（生徒に見せないよう、普段は隠しておく。タイトルの1文字を押すと開く**隠しボタン**）
  - 前方：指定した出席番号の生徒を前2列のどこかに置く。
  - 別：1行に1グループで「この生徒同士は隣り合わせない」（上下左右・斜め）。
  - 空席：マスを押して「×」にした席には誰も座らせない。人数が少ないときは後ろの席から自動で空ける。
  - 座席の指定：生徒を選び、座ってよい席に ✓ を付ける（複数可）。行・列ごとの一括切り替え。
- 実行すると条件を満たす配置を3パターン作る。男女がまわり8マスで1人だけにならないようにする。
- 条件が厳しくて見つからないときは「条件を緩和して」と表示する。斜めの制約は、一定回数試してだめなら自動で外す。
- 結果の表示を「氏名」と「出席番号」で切り替え。男女で薄く色分け。
- 印刷（結果だけ。条件設定や配慮の印は出さない）。

**あれば便利**
- 条件をブラウザに自動保存し、次回も使えるようにする（出席番号と席番号だけ。氏名は保存しない）。
- 実行前の点検（指定した席がすべて空席になっている生徒がいたら知らせる）。
- 列数・行数を変えられる設定。

## 4. 画面の流れ
1. アプリを開き、名簿の Excel をドロップする。
2. （必要なときだけ）隠しボタンで条件設定を開き、前方・別・空席・座席の指定を入れる。
3. 「席替えを実行する」を押す。
4. 3パターンの座席表が出る。氏名／出席番号を切り替えて、プロジェクターで見せる。
5. 採用するパターンを印刷する。

## 5. 扱うデータ
- 入力：名簿ファイル（例）
  - `出席番号, 氏名, 性別`
  - `1, 青木 蓮, 男`
- 条件（ブラウザに保存）：前方の出席番号の一覧、離したいグループの一覧、空席の席番号、生徒ごとの「座ってよい席番号」の一覧。
- 出力：画面上の座席表（6列×7行）と、その印刷。ファイルは書き出さない。

## 6. 個人情報の扱い
- 名簿は**ブラウザの中だけで読み込み・処理**し、どこにも送信しない。サーバー・DB・AIは使わない。
- 保存するのは条件（出席番号と席番号）だけで、氏名は保存しない。名簿は毎回読み込み直す。
- 配慮の内容（誰をどこに座らせたいか）は画面にも印刷にも出さない。
- インターネットにつながっていなくても動くよう、Excel 読み込み用のライブラリもアプリと一緒に置く。

## 7. 技術の例
- 例：**HTML 1枚＋JavaScript**（ビルド不要。ファイルをダブルクリックすれば動く）。
- Excel の読み込みは SheetJS などのライブラリを同じフォルダに置いて使う。
- 配置は「ランダムに並べる → 条件を満たすか点検 → だめならやり直す」を数千回まで繰り返す方式で十分速い。条件の厳しい生徒（座席の指定がある生徒）から先に置くと詰まりにくい。

## 8. AIに作らせるときのコツ
- 条件（前方・別・空席・座席の指定・男女の孤立防止）と、それぞれの優先順位を先に文章で決めて渡す。
- 架空の名簿（40人程度）を AI に作らせて、厳しい条件でも3パターン出るか試す。
- 「配慮の印は結果に一切出さない」「隠しボタンで開く」を最初から要件に書いておく。
