# Cloze Test & 整序メーカー 要件定義（略案）

> 登録した英文から、穴埋め（Cloze Test）と語順並べ替え（整序）の練習問題を自動で出すアプリ。

## 1. 目的
- 教科書本文などの英文を使って、生徒が自習できる穴埋め・整序問題を作る手間をなくす。
- 難易度や解答方法を切り替えて、同じ英文を繰り返し練習できるようにする。

## 2. 使う人
- 生徒：スマホやPCで練習する。
- 教員：英文データ（レッスン・パートごとの本文と和訳）を登録・更新する。

## 3. 主な機能
**必須**
- レッスン・パートを選んで、モード（Cloze／整序）を選ぶ。
- Cloze：本文の単語を一定間隔で空欄にする。難易度は「やさしい（7語ごと）／ふつう（5語ごと）／むずかしい（3語ごと）」。
- Cloze の解答方法を切り替え：①タップで答えを表示　②入力して自動採点。採点は大文字小文字と記号を無視した完全一致。
- 整序：1文を単語に分けてシャッフルし、タップで並べ直して正誤判定。
- 空欄は元データを書き換えず、**表示のたびに計算で作る**（難易度の切り替えが即時にできる）。

**あれば便利**
- 和訳の表示／非表示。正答数の表示。
- 間違えた問題だけのやり直し。
- 教員用：スプレッドシートから英文データを一括取り込み。

## 4. 画面の流れ
1. トップ：Cloze か整序かを選ぶ。
2. レッスン・パートを選ぶ（必要なら難易度・解答方法も）。
3. 問題画面：空欄を埋める／単語を並べる。
4. 「答え合わせ」で正誤を表示し、和訳と正解を確認。
5. 次のパートへ、または選び直し。

## 5. 扱うデータ
- 英文データ（JSON、またはスプレッドシート／CSVから変換）。列の例：
  - Cloze用：`lesson, part, title, display_order, body（英文）, trans（和訳）`
  - 整序用：`lesson, part, title, seq（文の順番）, sentence（英文1文）, trans`
- 並び順は行の順番（＝本文の流れ）で決める。番号列に頼らない。
- 句読点は単語にくっついたまま扱うと、略語（Dr. など）や引用符が崩れにくい。
- 出力：画面表示のみ。必要なら印刷用の表示。

## 6. 個人情報の扱い
- 英文データには**個人情報を含めない**（教科書本文と和訳だけ）。
- 生徒の氏名・成績は保存しない構成を推奨。正答数などはブラウザ内だけに持たせる。
- このアプリは**AIを使わずに作れる**ため、外部AIには何も送らない設計にできる。
- 教科書本文を使う場合は、公開リポジトリに載せず、非公開で運用するか自作の英文を使う（著作権への配慮）。

## 7. 技術の例
- 例：1枚のHTML＋JavaScript（英文データをJSONで同梱）。
- 発展：Next.js＋Vercel で配信し、データを Supabase などのデータベースに置く。その場合も接続情報は環境変数に置き、ソースに書かない。

## 8. AIに作らせるときのコツ
- 最初に英文データのサンプル（3〜5文）を渡し、「元データは書き換えず、表示時に空欄を作る」と指示する。
- 空欄にする条件（N語ごと・記号だけの語は除く）と採点ルールを文章で具体的に伝える。
- Cloze と整序は別画面として、1つずつ順に作らせる。
