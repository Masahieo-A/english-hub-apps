# 構文図解メーカー 要件定義（略案）

> 英語の複雑な文構造を、樹形図・色分け・注釈で図解し、生徒に配れる1枚のHTMLとして書き出す教員向けアプリ。

## 1. 目的
- 文の構造（主語・動詞・修飾関係など）を「見て分かる」教材にする。
- AIが下書きを作り、教員が細部を直して仕上げる。コード（HTML/CSS）は触らない。

## 2. 使う人
- 英語科教員（作成・編集）。生徒は書き出されたHTMLを開いて見るだけ。

## 3. 主な機能
**必須**
- 英文（1行に1文）を入力し、「AIで下書き」で構造データを作る。
- 色分け文：役割（主語S・動詞V・目的語O・補語C・修飾語M・接続語）ごとに色と印（下線の種類など）を変えて表示する。
- 樹形図：文を意味のまとまり（チャンク）に分け、枝分かれで表示する。
- ノード編集：クリックした部分の文言・役割・生徒向けの注釈を直せる。
- HTML書き出し：CSSもデータも1ファイルに含めた、ネット接続なしで開けるHTML。
- 取り消し／やり直し。

**あれば便利**
- 和訳・解説の見出しや段落の追加。教材の一覧、複製、一括バックアップ。
- PDFや既存HTMLの取り込み。色覚に配慮して、色だけでなく印（二重線・波線など）でも区別する。

## 4. 画面の流れ
1. 教材の一覧／新規作成。
2. 英文を入力して「AIで下書き」。
3. 構造エディタ：色分け文・樹形図を見ながらノードを選んで編集。
4. 書き出しプレビューで確認。
5. 「HTMLをダウンロード」して生徒に配布（ファイル共有・LMSなど）。

## 5. 扱うデータ
- 中心は「教材データ」（JSON）。HTMLを直接いじらず、データから画面を作る方式にする。
  - 例：`{ title, rolePalette（役割名→色）, blocks: [見出し／段落／文／樹形図／注釈…] }`
  - 文の1チャンク：`{ id, role, text, note, children: [...] }`
- 入力：英文テキスト（必要ならPDF）。出力：教材JSON、配布用HTML。
- 書き出しHTMLにデータを埋め込むと、配布物がそのままバックアップになる。

## 6. 個人情報の扱い
- 扱うのは英文と解説だけ。**生徒の情報は一切入れない**。
- 教材データの保存先はブラウザ内（localStorage）か、教員のPC上のファイルに限る構成を推奨。
- AIに送るのは英文（と教員の指示文）だけ。教科書本文を使う場合は著作権に配慮し、公開物には載せない。

## 7. 技術の例
- 例：Next.js＋TypeScript＋Vercel（AI呼び出しをサーバー側で行うため、静的ページ単体では足りない）。
- AIは Claude や Gemini などのAPIから選べる。**APIキーはサーバー側の環境変数に置く**。共有キーを使うなら、合言葉などのアクセス制限と回数制限を付ける。
- 簡易版なら、AIチャットに教材JSONの形式を渡して出力させ、1枚のHTMLビューアで表示する方法でも作れる。

## 8. AIに作らせるときのコツ
- 最初に教材データの型（TypeScript の型やJSON例）を決めて渡すと、描画・編集・AI出力がずれない。
- 「見た目を直接編集しない。データを編集して再描画する」方針を明記する。
- 表現しきれない例外用に、生HTMLを置ける「逃げ道ブロック」を1種類だけ用意させる。
