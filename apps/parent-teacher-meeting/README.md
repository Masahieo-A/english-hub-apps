# 保護者懇談会 日程調整 要件定義（略案）

> 保護者の希望日時を集め、重複しない懇談会の時間割を自動で作る教員向けアプリ。

## 1. 目的
- 希望調査から時間割づくりまでの手作業（表の突き合わせ）をなくす。
- できるだけ多くの家庭の希望を叶える。

## 2. 使う人
- 教員（担任など）：枠の設定・割り当て・出力。
- 保護者：希望日時を回答するだけ（アプリへのログイン不要）。

## 3. 主な機能
**必須**
- 懇談会の設定：クラス名、日程、時間帯、1枠の長さ（例：15分）、提出期限。
- 保護者の回答の収集：フォームの回答表（.xlsx／CSV）を読み込む。
- 自動割り当て：1枠につき1家庭。各家庭が選んだ枠の中だけで、できるだけ多くの家庭が入るよう最適化（**最大マッチング**）。
- 結果の確認（表）と、Excel（.xlsx）出力。
- 未提出・割り当てできなかった家庭の一覧表示。

**あれば便利**
- 手動での微調整（枠の入れ替え）。
- 提出状況の一覧、バックアップ／復元（JSON）。
- 保護者向けのタップ入力画面（○を付けて送信）。
- 保護者に配るフォームの作り方の手順書。

## 4. 画面の流れ
1. 懇談会の情報（日程・時間枠）を確認・設定。
2. 保護者に希望調査フォームを配る（フォームの選択肢は時間枠と同じにする）。
3. 回答表（.xlsx／CSV）を読み込む。
4. 「自動で割り当てる」を押す。
5. 結果を確認し、必要なら調整して、Excelに出力する。

## 5. 扱うデータ
- 入力（回答表）の列の例：`回答日時, 出席番号, 生徒名, 保護者名, 参加できる日時（複数選択）, 備考`。
  - 「参加できる日時」は `12/15(火) 16:00, 12/15(火) 16:15, …` のようなカンマ区切りで、時間枠の表記と一致させる。
- 出力：`日付, 時間, 出席番号, 生徒名` の時間割表（.xlsx）。
- 内部：家庭と枠を結ぶ「二部グラフ」を作り、最大マッチングのアルゴリズム（増加路を探す方法）で割り当てる。

## 6. 個人情報の扱い
- 生徒名・保護者名・出席番号が入るため、**AIは使わず、外部へ送信しない**設計を推奨。
- データはブラウザ内（localStorage）で処理し、サーバーや外部データベースに送らない。読み込んだファイルも送信しない。
- 作業後は保存したExcel／JSONの保管場所に注意し、不要になったブラウザ内データは消す。
- 回答はフォームの管理者（教員）だけが見られるように設定する。

## 7. 技術の例
- 例：**HTML＋CSS＋JavaScript だけの静的ページ**（ビルド不要）。Excel読み書きに SheetJS などを使う。
- 回答収集は Google フォームなど既存サービスを使い、アプリは「読み込み→割り当て→出力」に専念すると作りやすい。

## 8. AIに作らせるときのコツ
- 回答表のサンプル（架空の家庭20〜40件）を先に作らせ、実データなしで動作確認する。
- 「1枠1家庭／希望外には割り当てない／最大数を割り当てる」という条件を、最初に文章で明記する。
- 割り当てロジックだけを先に作ってテストし、その後で画面とExcel出力を足す。
